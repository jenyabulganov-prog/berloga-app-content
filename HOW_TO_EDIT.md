# Как менять страницу магазина

Это хранилище содержит только публичную информацию, видимую игрокам. Исходников приложений, ключей, паролей и данных пользователей здесь нет. Редактирование доступно владельцу аккаунта GitHub.

1. Откройте [редактор страницы маджонга](https://github.com/jenyabulganov-prog/berloga-app-content/edit/main/mahjong.json).
2. Замените текст внутри кавычек у нужных полей. Сохраните кавычки, запятые и фигурные скобки.
3. Нажмите **Commit changes**, затем подтвердите сохранение в **main**.
4. Откройте страницу магазина в игре с интернетом. Изменения появятся после обновления файла и кеша, обычно в течение нескольких минут. APK обновлять не нужно.

| Поле | Что меняет | Ограничение |
|---|---|---|
| title | Заголовок «Берлога» | До 40 символов |
| description | Основной текст | До 180 символов |
| footer | Подпись над кнопкой | До 80 символов |
| buttonText | Надпись на кнопке Ozon | До 40 символов |
| imageUrl | Иллюстрация вместо золотого лотоса | Прямой публичный HTTPS-адрес PNG/JPEG/WebP; до 2 МБ, максимум 4096×4096 |

Пустой imageUrl оставляет золотой лотос. schemaVersion оставьте равным 1. Ссылка перехода в магазин закреплена в приложении: https://www.ozon.ru/seller/berloga-ozon/ . Она не меняется через этот файл.

Без интернета игра показывает последнюю корректную информацию, а при первом запуске — встроенную. Ошибочный или слишком длинный файл не заменяет сохранённый. Нефритовое оформление остаётся частью игры. Старые APK без поддержки удалённого содержимого обновляться не смогут; сначала нужен выпуск APK с этой функцией.

Сейчас файл подключён только к Android-маджонгу. В медицинских панелях, закрытой Ферме и версиях для Яндекс Игр магазин не подключается. Каждый новый проект требует отдельного согласия владельца.
